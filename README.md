# 🏨 Hotel & Hospitality Performance Dashboard

## 📊 Project Overview

The **Hotel & Hospitality Performance Dashboard** is an interactive Business Intelligence project developed using **Microsoft Power BI** to analyze hotel booking and hospitality performance.

The dashboard transforms booking data into meaningful business insights related to **bookings, revenue, occupancy, ADR, cancellations, customer behaviour, demand patterns, room types, properties, and booking channels**.

The main goal of this project is to help hotel management understand operational and financial performance and make data-driven decisions.

---

## 🎯 Problem Statement

Hotels generate large volumes of booking and operational data, but analyzing this information manually can make it difficult to identify important performance trends.

This project addresses that challenge by developing an interactive Power BI dashboard that helps management:

* Monitor overall hotel performance.
* Analyze booking and revenue trends.
* Evaluate occupancy and ADR performance.
* Identify peak and low-demand periods.
* Compare property and room-type performance.
* Understand customer booking patterns.
* Analyze booking channels.
* Identify cancellation trends.
* Measure the revenue impact of cancellations.
* Support data-driven business decisions.

---

## 🎯 Project Objectives

The main objectives of this project are:

1. Analyze total bookings, revenue, occupancy rate, ADR, and cancellation rate.
2. Identify booking and revenue trends over time.
3. Analyze property and room-type performance.
4. Understand customer types and booking behaviour.
5. Analyze booking channels and their revenue contribution.
6. Identify cancellation patterns and their financial impact.
7. Identify peak and low-demand periods.
8. Provide an interactive dashboard for management decision-making.
